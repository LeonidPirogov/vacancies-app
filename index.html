🔧 Как исправить — настройка правил Firestore:
1. Открой console.firebase.google.com
2. Выбери свой проект → Firestore Database → вкладка Rules
3. Замени всё содержимое на:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
} 4. Нажми Publish → обнови страницу сайта
